# Agent instructions

This repository follows the contributing guide in `docs/contributing/`.
Read `docs/contributing/00-index.md` before doing anything else, then follow
it for every change: principles, workflow, quality gates, testing, git
conventions, security, documentation, and verification.

If this repo has its own project-level instructions elsewhere (a `CLAUDE.md`,
`.cursor/rules`, or a nested `AGENTS.md`), those win where they conflict with
this file. If this file was copied in from the agent-contributing-template,
keep the `docs/contributing/` files as the shared standard and do not rename
or split them.
